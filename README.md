# CodeAlpha Calculator

A responsive and interactive calculator built with **HTML, CSS, and Vanilla JavaScript** as part of the **CodeAlpha Frontend Development Internship – Task 2**.

The project demonstrates practical frontend development skills, including DOM manipulation, event handling, input validation, application state management, keyboard interactions, and responsive UI design.

## Live Demo

**[View Live Demo](https://mohamedashraf-a.github.io/CodeAlpha_Calculator/)**

## Overview

This calculator provides a clean and straightforward interface for performing common arithmetic operations.

The application is built entirely with vanilla web technologies without external frameworks or dependencies, keeping the implementation lightweight and easy to understand.

## Features

* Basic arithmetic operations

  * Addition
  * Subtraction
  * Multiplication
  * Division
  * Modulo
* Decimal number calculations
* Clear and delete functionality
* Keyboard input support
* Division-by-zero error handling
* Input validation
* Prevention of duplicate decimal points
* Prevention of unnecessary leading zeros
* Responsive layout for different screen sizes
* Interactive button states
* Lightweight implementation with no external dependencies

## Keyboard Support

| Key           | Function       |

| `0–9`         | Enter numbers  |

| `+`           | Addition       |
| `-`           | Subtraction    |
| `*`           | Multiplication |
| `/`           | Division       |
| `%`           | Modulo         |
| `Enter` / `=` | Calculate      |
| `Backspace`   | Delete         |
| `Escape`      | Clear          |

## Implementation

The calculator is structured around a small state-management system that keeps track of:

* Current input
* Previous input
* Selected operation
* Display reset state

JavaScript event listeners handle both button interactions and keyboard input, while dedicated functions manage calculations, display updates, clearing, deletion, and operation selection.

The implementation also includes basic validation to provide a more reliable user experience.
